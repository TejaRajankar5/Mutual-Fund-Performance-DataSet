# 📈 Mutual Fund Performance & Risk Analysis Dashboard

![Project image](mutual funds.png)
## 📌 Project Overview

This project provides a **comprehensive analysis of mutual fund performance** across different **fund houses, investment types, categories, risk levels, and time periods**.
The dashboards are designed to help investors and analysts understand **returns, risk exposure, asset allocation, and market share** using interactive visual analytics.

The project is ideal for:

* Tableau / Power BI portfolio
* Finance & investment analytics projects
* Academic mini or major projects
* Interview demonstrations

---

## 📊 Dashboards Included

## 1️⃣ Mutual Fund Performance Overview

<img width="1655" height="854" alt="Mutual Fund Performance Overview" src="https://github.com/user-attachments/assets/f2701302-0ce9-4f02-b698-113cf8387000" />

This dashboard gives a **high-level summary of the mutual fund ecosystem**.

### 🔹 Investment Type Distribution (Pie Chart)

* Compares:

  * Open Ended Funds
  * Close Ended Funds
* Shows investor preference and fund structure dominance.

### 🔹 Fund House–wise Total AUM (Bar Chart)

* Displays total **Assets Under Management (AUM in ₹ Crores)** for:

  * Kotak MF
  * ICICI Prudential
  * Nippon MF
  * HDFC MF
  * Axis MF
  * SBI MF
* Helps identify **market leaders by asset size**.

### 🔹 Category-wise Average 5Y Return (Bar Chart)

* Fund categories:

  * Index
  * Hybrid
  * Equity
  * Debt
* Highlights which category delivers **higher long-term returns**.

### 🔹 Fund House Market Share by AUM (Treemap)

* Shows how AUM is distributed across:

  * Fund Houses
  * Fund Categories
* Useful for **market share comparison and portfolio concentration analysis**.

## 2️⃣ Returns & Risk Analysis

This dashboard focuses on **performance trends and risk evaluation**.

### 🔹 Year-wise Average NAV Trend (Line Chart)

* Covers years **2015 to 2024**
* Tracks average Net Asset Value (NAV) movement
* Helps analyze **long-term growth stability**.

### 🔹 Risk vs Category Heatmap

* Risk levels:

  * Low
  * Moderate
  * High
* Fund categories:

  * Debt
  * Equity
  * Hybrid
  * Index
* Visualizes how **risk is distributed across categories**.

### 🔹 Top 10 Funds by 5Y Return (Horizontal Bar Chart)

* Ranks top-performing funds based on **5-Year Return %**
* Helps identify **best-performing investment options**.

## 🚀 How to Use This Project

1. Open the Excel dataset.
2. Import it into **Tableau or Power BI**.
3. Recreate dashboards using the same visual structure.
4. Use filters for:

   * Fund Category
   * Investment Type
   * Risk Level
   * 5Y Return %

## 📌 Key Insights

* Index and Equity funds show higher long-term returns.
* Debt funds exhibit lower risk with stable performance.
* Certain fund houses dominate AUM market share.
* Higher returns are generally associated with moderate to high risk.
